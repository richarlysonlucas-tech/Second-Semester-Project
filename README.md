# Second-Semester-Project

# 1. Introdução

Propósito do Produto:

- O que é o projeto? O software a ser desenvolvido é um jogo digital do gênero Action-RPG (RPG de Ação) Single-Player, ambientado no universo de fantasia de Aetheria.

Escopo de Alto Nível:

- Sistema de Combate Dinâmico: Implementação de estilos de luta distintos, que o jogador desbloqueia ao longo da campanha.

- Progressão e Inventário: Sistema para coletar, equipar e melhorar os itens e habilidades ligadas à marca do (Símbolo do Equilíbrio).

- Mundo Semi-Aberto (Hub-and-Spoke): Design de níveis dividido em 3 biomas temáticos (terras dos impérios) acessados a partir de um mapa central, com perigos ambientais que refletem a "geografia instável".

- Inimigos: Comportamentos programados para criaturas básicas (Os Corrompidos) e com batalhas de chefes principais (Líderes das Sombras ou Guardiões Corrompidos).

- Ciclo de Jogo Principal: Explorar -> Combater -> Coletar Fragmento -> Purificar no Conselho -> Desbloquear nova área/habilidade.
